2.1Scope

  1. This section outlines the stepbystep procedures required for assembling the Lift assembly.
Note
Prior to commencing assembly of each of the units described in this guide, make sure the relevant ATP documents are properly signed.
Spread Loctite 243 or similar glue on all the screws unless stated otherwise.
Tightening of screws will be done according to the Screw Torque Table included in this document. (See Appendix TBD).

  1. Using an 8 mm Allen bit, install two M10 Allen-head screws (2) and two M10 flat washers (3) which secure the Left Beam (1) to the UPS and FAN Electrical Assembly.

  3. Position eight Tie Mounts (8) on the installation bores of the Beam (1).
  4. Using a 4 mm Allen-head bit, install eight M5 Allen-head screws (7) which secure eight Tie Mounts (8) to the Left Beam (1).

2.4.1.9Installation Procedure

.

  1. Perform Plunger Assembly as follows:
    1. Install Plunger Nut (2) on the Plunger (3), tighten manually till end of move.
    2. Install Securing Nut (1) on the Plunger (3), tighten manually till end of move.
Note Note
The Plunger Assy (4) threading must be flush on the other side of the Stopper (5).
  1. Install the plunger assy. (4) into the stopper (5) by threading it into the designated bore.
  2. Secure the Plunger assy. (4) in the Stopper (5) by threading the Plunger Nut (1) towards the Stopper (5), tighten the Plunger Nut (1) to the Stopper (5) by hand force.
  1. Repeat steps ‎1.a to ‎1.d for the second Plunger.
  2. Install upper plunger as follows:
    1. Position the Stopper with Plunger (7) in its place on the Beam (6).
    2. Insert a Spacer (8) into installation bore.
    3. Using an 8 mm Allen-head bit, install M10 Allen-head screw (10) and spring washer (9) which secure Stopper with Plunger (7) to the Beam (6).
  3. Repeat steps ‎3.a to ‎3.c for lower plunger installation.
  4. .
  5. Install Upper Plunger Sensor as follows:
    1. Position upper Sensor Bracket (2) in its place on the Left Beam (1).
    2. Using a 3 mm Allen-head bit, install two M4 Allen-head screw (3) which attach Sensor Bracket (2) to the Left Beam (1).
    3. Thread the sensor nut (5) down until it reaches the sensor base.
    4. Insert the Inductive Sensor (4) into Sensor Bracket (2) installation bore.
    5. Thread the sensor locking nut (6) down until it reaches the sensor base.
    6. Measure the distance between the Inductive Sensor tip (4) and the Stopper (6).
    7. Adjust the distance (8) between Inductive Sensor tip (4) and the Stopper (7) to 1.25 mm ±0.25 mm by adjusting sensor nut (5) and locking nut (6).
    8. Using a 17 mm open-wrench, tight the plunger sensor locking nut (6) until it reaches the Sensor Bracket (2).
  6. Repeat steps ‎5.a to ‎h for Lower Sensor Bracket.
  7. Install Lifting Eyebolt (9) on the Left Beam (1) by threading it into its bore.

2.4.3.2Assembly Procedure

.

  1. Position Motor (5) in its place (ensuring the orientation matches the direction indicated as 5*) on the Gear (1).
  2. Using a 5 mm Allen-head bit and a 10 mm open-end wrench, install four M6 Allen-head screws (4), four flat washers (3) and four M6 nuts (2) which secure the Motor (5) to the Gear (1).
  3. Position Gear Mount (7) in its place on the Drive Shaft Gear (1).
  4. Using a 6 mm Allen-head bit and a 6 mm open-end wrench, install four M8 Allen-head screws (9), four flat washers (8) and four M8 nuts (6) which secure Gear Mount (7) to Drive Shaft Gear (1).
  5. Install 90 mm Feather Key (12) in its place on the Drive Shaft (11).
  6. Insert the Drive Shaft (11) into Drive Shaft Gear (1), make sure to align 90 mm Feather Key (12) with the Drive Shaft groove.
  7. Install 28 mm Feather Key (13) in its place on Drive Shaft (11).
  8. .
  9. Slide the Sprocket (2) onto Drive Shaft (1), make sure to align 28 mm Feather Key (4) with the Sprocket groove (5).
  10. Push the Sprocket (2) as to the end on Drive Shaft (1) so the Drive Shaft groove will be visible.
  11. Using circlip pliers, install circlip (3) in its groove on the Drive Shaft (1).
  12. Install Housing Bearing (6) onto Drive Shaft (1).
  13. Using an 8 mm Allen bit, install M10 Allen-head screw (8) and flat washer (7) which secure the Housing Bearing (6) on the Drive Shaft (1).
  14. On the other side of the Drive Shaft, Install 28 mm Feather Key (14) in its place on the Drive Shaft (1).
  15. Slide the Sprocket (13) onto Drive Shaft (1), make sure to align 28 mm Feather Key (14) with the Sprocket groove (15).
  16. Position the Sprocket (13) as close as possible to Drive Shaft (1) so the Drive Shaft groove will be visible.
  17. Using circlip pliers, install circlip (12) in its groove on the Drive Shaft (1).
  18. Install Housing Bearing (11) onto Drive Shaft (1).
  19. Using an 8 mm Allen bit, install M10 Allen-head screw (9) and flat washer (10) which secure the Housing Bearing (11) on the Drive Shaft (1).

2.4.6.2Adjustment Procedure

.

  1. Install one M10 nut (7) onto the Swing Bolt (6) and thread the nut down until it reaches the bolt base.
  2. Install two flat washers (8 and 9) onto the Swing Bolt (6).
  3. Install another M10 nut (10) onto the Swing Bolt (6) and thread the nut close to both flat washers (8 and 9).
  4. Connect the Swing Bolt (6) to the Roller Chain (1) as follows:
    1. Insert a Chain Centering (5) into Swing Bolt (6) bore.
    2. Insert Pin Assembly (2) through the Swing Bolt (6) bore and the Chain installation bores.
    3. Install Link Plate (4) on Pin Assembly (2) both pins.
    4. Install spring Clip (3) on Pin Assembly both pins (2) groove to secure the Swing Bolt (6) to the Roller Chain (1).
  5. Fully extend the Roller Chain (1) and measure 2.88 meters from the end, corresponding to 152 pins.
  6. Remove the connection pin (11) from Roller Chain 152nd pin (1).
  7. Repeat steps ‎1 to ‎4 to install another Swing Bolt (6) on the other end of the Roller Chain (1).

2.4.14Lift Assembly Calibrations

.

  1. Left and Right Roller Assembly Calibration:
    1. Connect Motion Jig to the Drive Shaft Motor connector, for Motion Jig Connection refer to OPT1-D-063.
    2. Lift the Lift Assembly 50 cm above the ground.
    3. Measure the distance between the Roller Base (2) and the Side Beam (1).
    4. Adjust the distance between Roller Base (2) and the Side Beam (1) to 3 mm as follows:
      1. Using a 5 mm open-end wrench, release M6 nut (3).
      2. Using a 5 mm open-end wrench, adjust the distance between Roller Base (1) and the Side Beam (2) by turning the M6 Fastner
        Screw (4):
        • Turn CW to increase the distance.
        • Turn CCW to decrease the distance.
      3. Using a 5 mm open-end wrench, tighten M6 nut (3).
    5. Repeat steps ‎a to ‎d for the other Roller Assembly (Left).
  2. .
  3. Inductive Sensors Calibration:
    1. Connect Motion Jig to the Drive Shaft Motor connector, for Motion Jig Connection refer to OPT1-D-063.
    2. Lower the Lift Assembly to the lower position.
    3. Using filler gauge, measure the distance between the Inductive Sensor tip (2) and the Flags Assembly (1).
    4. Adjust the distance between Inductive Sensor tip (2) and the Flags Assembly (1) to 1.25 mm ± 0.25 mm:
      1. Using a 17 mm open-end wrench, release two M10 nuts (3, 4), one from each side of the horizontal beam (5).
      2. Position Inductive Sensor tip (2) at 1.25 mm ± 0.25 mm from the Flags Assembly (1).
      3. Using a 17 mm open-end wrench, tighten two M10 nuts (3, 4).
    5. Lift the Lift Assembly to the upper position.
    6. Repeat steps ‎c and ‎d for the upper Inductive Sensor.
