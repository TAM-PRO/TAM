# מערכת איתור ופתרון תקלות

פרויקט זה נבנה באמצעות React ו-Vite, וכולל ממשק לבניית עצי תקלות (Builder) וכן אפשרות לייצא את עץ התקלות לקובץ HTML עצמאי.

## הפעלה פשוטה (ללא התקנה)
כדי להשתמש במערכת ישירות מהמחשב שלך ללא צורך בהתקנת תוכנות נוספות:
1. חלץ את קובץ ה-ZIP שהורדת לתיקייה במחשב שלך (חשוב לחלץ ולא לפתוח ישירות מתוך ה-ZIP).
2. לחץ פעמיים על הקובץ **`index.html`** שנמצא בתיקייה הראשית.
3. הדפדפן ייפתח והמערכת תעבוד מיד!

*הערה: הקובץ `index.html` כבר כולל בתוכו את כל הקוד, העיצוב, ומפתח ה-API שהיה מוגדר במערכת בעת ההורדה, כך שהצ'אטבוט יעבוד מיד.*

## למפתחים (הפעלה עם Node.js)
אם ברצונך לערוך את הקוד ולהריץ את סביבת הפיתוח:

1. **התקנת תלויות:** פתח את התיקייה בטרמינל והרץ:
   ```bash
   npm install
   ```

2. **הגדרת מפתח API:**
   צור קובץ `.env` בתיקיית השורש והוסף:
   ```env
   GEMINI_API_KEY=YOUR_API_KEY
   ```

3. **הפעלת שרת הפיתוח:**
   ```bash
   npm run dev
   ```

## ייצוא ל-HTML
בתוך המערכת, תוכל ללחוץ על "ייצא ל-HTML". פעולה זו תיצור קובץ HTML עצמאי הכולל את כל עץ התקלות, הצ'אטבוט, אפשרויות החיפוש והזום.

## ייבוא מאקסל
ניתן להוריד תבנית אקסל מהמערכת, למלא אותה בנתוני התקלות, ולייבא אותה חזרה כדי ליצור עץ תקלות באופן אוטומטי.
